# مشجرة عائلة آل خميس الكبرى — الشجرة الأنسابية الجامعة
### The Grand Al-Khamis Family Tree (Archival Heirloom Edition)

المشجرة الأنسابية التفاعلية الشاملة والموثقة لعائلة **آل خميس** من آدم عليه السلام إلى اليوم، مستخلصة من الأرشيف التاريخي (461 صفحة) ومبنية بأحدث تقنيات الويب التفاعلية.

🌐 **رابط المشجرة المباشر (Live Site):**  
👉 [https://fgohako.github.io/alkhamis-tree/](https://fgohako.github.io/alkhamis-tree/)

---

## 🌟 المزايا والخصائص الفنية (Features)

- **هندسة الشجرة العمودية التراثية (Tall-Tree Symmetrical Cascade Layout):** تصميم طولي متناسق مستلهم من المشجرات التراثية العريقة ومناسب لشاشات الهواتف والأجهزة اللوحية دون استطالة أفقية مفرطة.
- **تجميع الفروع والأجيال الطرفية:** تجميع الأفراد غير المتفرعين في شبكات مضغوطة ومنظمة أسفل آبائهم مع الحفاظ على الأنساب وسلاسل البنوة (`بن` / `بنت`).
- **خطوط أنساب عالية التباين (High-Contrast Kinship Lines):** خطوط ذهبية براقة (`#f59e0b`) في الوضع الليلي وبرونزية ملكية (`#78350f`) في الوضع الورقي الكلاسيكي، مع مؤشرات واضحة للأسهم والروابط الزوجية (`💍`).
- **أداء استثنائي على الهواتف (60 FPS Mobile GPU Engine):** تسريع عتادي كامل وتمرير فائق السلاسة بتقنية `requestAnimationFrame` وتأجيل المعالجة الثقيلة أثناء السحب والتكبير/التصغير.
- **تطبيق ويب تقدمي (PWA):** إمكانية التثبيت المباشر على شاشة الهاتف الرئيسية والعمل دون اتصال بالإنترنت.
- **HUD ومسار الأنساب العصبي:** فحص فوري للأسلاف، الإخوة، الأعمام، أبناء العم، والذرية المتفرعة لكل فرد بنقرة واحدة.

```text
├── sw.js                 # Service Worker للتخزين المؤقت والتشغيل أوفلاين
├── .nojekyll             # تعطيل معالجة Jekyll على GitHub Pages
└── public/
    ├── family_data.js    # قاعدة بيانات الأنساب الكاملة (3,000+ فرد)
    ├── icon-192.png      # أيقونة التطبيق (192x192)
    └── icon-512.png      # أيقونة التطبيق (512x512)
```
